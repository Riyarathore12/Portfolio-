# Riya Rathore — Professional AI/ML Portfolio

This version embeds the supplied profile photo directly inside `index.html`, so the photo will still display when only `index.html` is uploaded to a static host.

## Animations
- Animated particle network background
- Scroll progress bar
- Cursor glow
- Section/card reveal on scroll
- Animated resume counters
- 3D hover tilt on profile and projects
- Floating profile/AI chips
- Rotating rings and glow
- Back-to-top button
- Smooth navigation
- Reduced-motion accessibility support

## Deploy
Upload `index.html` directly to Vercel/Netlify/GitHub Pages, or upload the entire folder.
